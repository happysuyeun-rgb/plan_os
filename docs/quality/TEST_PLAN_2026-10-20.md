## 필수 fixture
- A 프로젝트 PRD·IA 2종과 정확/모순/빈/중복/존재하지 않는 인용 locator, 오래된 document digest, 원고 내용 속 공격 문구.
- B 프로젝트 documentId/계약/approvalId를 A run과 섞는 교차 테넌트 입력, revocation·만료된 계약과 역할 변경.
- 같은 idempotency key+같은 payload와 다른 payload, 이중 예약·provider usage 중복, lost response/503, 장시간 queued, worker lease 만료·재claim, 취소 직후 provider callback.
- human accept/reject/needs_revision 동시 POST, 원가 pending/settled/credit adjustment, 브라우저 reload 및 다중 탭.
- 외부 실제 모델·결제·이메일·삭제·배포 대신 mock/recorded fixtures 사용.

## 게이트
- **G0** 문서·FR/TF/API/DB/QA 추적 누락 검사, 정책 결재 대기 구분.
- **G1** Phase 0 기존 앱 CI·Chromium+일회용 DB 회귀·권한/RLS/직접 쓰기 보안 결함 해결.
- **G2** P1-5 정확한 OpenAPI·SQL/RLS/인증/원가/만료·CAS·provider callback 격리 테스트 PASS.
- **G3** 4역할 E2E·오류/재시도·browser resume·mobile/accessibility·보안 위협 negative PASS.
- **G4** 공급자 약관·개인정보/보존/가격/예산·kill switch/backup/롤백 실제 검증 + owner 사전 승인.
- **G5** 제한 파일럿 승인, 실제 사용자 수락/오탐·원가 기록; 지표는 측정 후 산정.

**STOP:** G0 문서만 통과해도 G1~G5 대신할 수 없다. 하나라도 P0 미통과면 Phase 1 구현 착수/릴리스 승인 불가. 실제 현장 통과 여부는 링크·CI/DB 증거 없으면 미검증으로 남긴다.
