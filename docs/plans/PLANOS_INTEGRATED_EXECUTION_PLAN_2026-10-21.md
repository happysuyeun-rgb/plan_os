### 선후관계·병렬 가능 업무
- **G0 → G1**은 기존 사용자 데이터 안전을 위한 차단 게이트. G1 완료 전에도 **G3/G4의 mock UI·순수 로직 개발**은 별도 브랜치에서 가능하지만 운영 데이터·모델 호출 연결 금지.
- **G2 완료 → G3/G4 서버 통합 → G5 → G6 → G7**이 실제 실행 연결의 필수 순서.
- DB **설계·SQL 정적 검수는 각 G 단계에서**, 격리 DB 실증은 기능 간 연결에 필요한 시점에 수행. **운영 DB 반영은 전체 검증·사용자 승인 뒤**.
- `main` 병합은 **코드 통합 행위**로 정의. 실제 출시/운영 가능 판정과 별개, 미검증 기능은 플래그·환경 경계 유지.
