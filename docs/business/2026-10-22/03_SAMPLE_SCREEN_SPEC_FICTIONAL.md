# [가상 입력 문서 B] 바른메이커 화면·기능명세 v0.1

> **합성 과제 — 의도적인 결함 포함.** [PRD](02_SAMPLE_PRD_FICTIONAL.md)와 동일한 가상 서비스이며 실제 PlanOS 화면 코드/정책이 아님.

## 화면 목록/플로우

### SCR-01 로그인 게이트
- 경로: `/onboarding`
- 방문자 상태: 인증되지 않은 사람에게 로그인 화면만 제공.
- 주요 CTA: '로그인하고 체험 시작'
- 구현 지시: **모든 체험 사용자는 로그인 필수.** 비회원 샘플·체험 구경 경로 없음.
- 예외: 미인증 리다이렉트 `/login`.

### SCR-02 요금제와 무료 체험
- 경로: `/settings/billing`
- 표시 문구: **“가입 후 7일 무료 체험”**
- 서버 계산: 가입 시각+7일을 `trial_ends_at`에 기록, 다음 날 청구 예약.
- CTA: 유료 플랜 선택 / 계속.
- 실패 상태: 결제 실패 카드 표시.

### SCR-03 프로젝트 업무 상세
- 경로: `/projects/:id/tasks/:taskId`
- UI: 역할과 관계없이 로그인 상태면 '수정' 및 '삭제' CTA 노출.
- 요청: `PATCH /api/tasks/:taskId`는 로그인 여부만 확인하고 owner/editor/viewer 역할을 확인하지 않는다.
- 수정 필드: 업무 제목·담당자·진척.
- 서버 응답: 변경된 객체 즉시 반환.

### SCR-04 계정 삭제 확인
- 경로: `/settings/delete`
- 고지: **“탈퇴 즉시 모든 개인 데이터가 영구 삭제됩니다.”**
- CTA: 계정 삭제 / 취소.
- UI에는 30일 처리기간이나 법정 보존 예외가 없다.

### SCR-05 PM 업무 완료 버튼
- 경로: `/projects/:id/tasks/:taskId`
- 완료 CTA: '업무 완료'를 누르면 즉시 `status=done`.
- 제출 산출물 링크·검증 근거·owner 수락 이벤트는 요구하지 않는다.
- 실패·중복: 별도 상태/재시도·멱등성 설계 없음.

## 화면 수준 테스트(작성된 초안)
- 로그인 여부에 따른 화면 진입
- 체험 7일 카운트다운
- 업무 수정 버튼 표시/저장 성공
- 회원 탈퇴 버튼을 누르면 확인 모달 표시
- 업무 완료 버튼 클릭 시 done 표시

### 의도적 검수 포인트
요구사항 검증이 버튼 클릭 수준에 멈춰 **정책, 역할별 접근, 검수·최종 수락, 실패 복구**를 건너뛴 명세이다. 보고서에서는 '동작한다'가 아니라 'PRD와 충돌하거나 필요한 계약이 빠져 있다'는 근거를 찾아야 한다.
