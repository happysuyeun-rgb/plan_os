# [가상 입력 문서 A] 바른메이커 웹서비스 PRD v0.1

> **합성 과제** · 실제 고객/PlanOS 개발 코드 또는 운영 정책 아님. [대응 화면명세](03_SAMPLE_SCREEN_SPEC_FICTIONAL.md)와 일부러 상충되게 설계함. 고객 검증용.

## 서비스 배경
- 가상 제품명: **바른메이커** — 소규모 제작사가 고객과 프로젝트 문서·업무를 공유하는 웹서비스.
- 가상 고객: 프로젝트 2~5개를 동시에 진행하는 1~5인 제작팀.
- 목적: 체험 → 팀 생성 → 업무 작성 → 결제/협업 → 프로젝트 완료 상태 추적.

## 요구사항
- **PRD-01 / 비회원 체험:** 비회원은 로그인 없이 3개의 샘플 프로젝트를 둘러볼 수 있으며 2번째 단계에서 회원가입을 선택적으로 권유한다. 체험 조회는 개인정보를 요구하지 않는다.
- **PRD-02 / 체험과 결제:** 신규 유료 플랜은 가입일부터 **14일 무료 체험**을 제공한다. 종료 후 첫 유료 청구를 진행한다. 실제 결제와 갱신은 고객 확인 후 활성화한다.
- **PRD-03 / 역할과 권한:** owner는 결제·계약·멤버 역할 변경·최종 승인, editor는 허용된 문서/업무 변경, **viewer는 열람만** 가능하다. UI와 API에 같은 권한을 강제해야 한다.
- **PRD-04 / 계정 탈퇴 데이터:** 탈퇴 요청이 접수된 개인 데이터는 **최대 30일 내 삭제**한다. 법정 보존의무 등 예외가 있으면 별도 고지한다.
- **PRD-05 / 업무 완료:** 프로젝트 업무는 제출된 산출물에 근거가 있고 담당 검수가 끝나며 **owner가 최종 수락**한 후 완료로 인정한다. 완료일·최종 수락자·버전 기록을 보존한다.
- **PRD-06 / 외부 데이터 전송:** 고객의 프로젝트 원문은 사용자 승인 없이 외부 모델 공급자/계정으로 전송하지 않는다.
- **PRD-07 / 오류 복구:** 자동저장·승인·업무 반영 중 실패할 경우 작성자의 입력을 보존하고 재시도/상태 확인 기능을 제공한다.

## 우선 성공기준
- TC-PRD-01 비회원 3개 샘플 조회가 로그인을 요구하지 않으며 제안된 2번째 지점에서만 가입 유도가 뜬다.
- TC-PRD-02 체험 종료 시각이 서버와 결제 화면 모두 14일 규칙에 일치한다.
- TC-PRD-03 viewer 계정으로 업무 PATCH 시 서버가 접근을 거부하고 기존 값이 변하지 않는다.
- TC-PRD-04 탈퇴 안내가 실제 개인 데이터 처리와 보존 예외를 정확히 반영한다.
- TC-PRD-05 제출→검수→owner 수락 기록이 없는 업무는 단순 버튼만으로 완료 표시되지 않는다.
